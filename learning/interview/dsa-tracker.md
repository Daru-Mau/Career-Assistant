Target: 60 problems in 12 weeks.

## Weekly routine

1. Pick five problems from the current topic.
2. Spend at most 30 minutes per problem before reading the solution.
3. Write the pattern and the mistake in the log.
4. Re-solve one problem from last week without looking.

## Interview readiness markers

- [ ] Can solve an easy problem in 20 minutes and explain complexity.
- [ ] Can solve a medium problem in 35 minutes with one hint at most.
- [ ] Can recognize the pattern before writing code.
- [ ] Can discuss tradeoffs and edge cases.
- [ ] Can code without an IDE in a shared document.
