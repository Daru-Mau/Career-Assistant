# Learning

A workspace for deliberate practice: plans, track checklists, project briefs, interview preparation and a weekly log. It is separate from `profile/` (facts) and `applications/` (submitted materials). Nothing here is an application artifact.

## Why this exists

The applications submitted between July and November 2026 show a consistent pattern: broad, credible projects, but missing depth proof in a few recurring areas.

- Full-stack and backend roles: Spring, Kafka, AWS, observability, production operations.
- Embedded and firmware roles: RTOS, ARM/STM32, BLE, PCB, EMC.
- AI roles: LLM, RAG, agents, evals, FastAPI.
- Local-market roles: Italian at a professional level.
- Interviews: DSA, system design and reasoning practice.

Sending more applications will not close these gaps. A small number of public artifacts and a language routine will.

## Goals for the next 12 months

1. Ship one public capstone: AI Document Assistant, covering full-stack, AI and security.
2. Reach solid B2+ Italian, with a path to C1.
3. Complete 60 DSA problems, 12 security labs and 5 STAR stories.
4. Optionally ship a small Spring Boot service to close the recurring Java gap.
5. Update CV and LinkedIn with the capstone and language progress.

## Rules

1. Output over input. Every week produces something visible: a commit, a lab write-up, a recording, a problem set.
2. One capstone, not three. Full-stack, AI and security are layers of the same project.
3. Log the week every Sunday, even if the week went badly.
4. Do not wait until week 12 to apply. Update the CV after week 8 and target roles that match the new proof.
5. Never claim a skill in an application before it has a project, lab or exercise behind it.

## Start here

1. Read `plan.md`.
2. Open `projects/01-ai-document-assistant/README.md`.
3. Set up the weekly review from `templates/weekly-review.md`.
4. Do the first Italian session and the DSA diagnostic in week 1.
